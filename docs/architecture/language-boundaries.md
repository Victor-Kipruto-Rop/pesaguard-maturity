# Language boundaries

- Java/Spring Boot: Daraja provider adapter, callback ingestion, transaction lifecycle, and tenant webhook delivery.
- Python/FastAPI: reconciliation, data quality, statement import, explainable risk rules, and reporting.
- Elixir/Phoenix: customer platform, organization workflows, developer experience, and real-time presentation.

Each capability needs a named data owner, versioned contracts, idempotent processing, tenant authorization, and independent tests. Do not add services just to increase service count. This scaffold is not production-ready until the implementation checklist is met.
